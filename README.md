Anitrack save file location : /home/user/.local/share/anitrack/


1- Install both ani-cli and anitrack first
2- Create a "ani-save" repo on github
3- On github again, create a token with "Contents" permission(read and write) (and for Repository access, select your ani-save repo) that you will use as a password, if git is asking you for one
4- Execute ani-save.sh, copy your ani-save repo URL from github, then enter username and token in the git text boxes
    You probably want git to remember your Username and password, so you are not interrupter each time you want to save
